# JavaScript Applications

A collection of interactive web applications developed using **HTML, CSS, and JavaScript**. This repository contains beginner-friendly projects designed to practice JavaScript concepts, DOM manipulation, events, functions, and dynamic web interfaces.

## 📌 Applications

### 🖼️ 1. Image Gallery

An interactive image gallery application created with HTML, CSS, and JavaScript.

**Features:**

* Display multiple images in a gallery
* Click images to view them
* Open images in a larger view
* Close the image preview
* Interactive user interface
* JavaScript event handling

**Technologies:**

* HTML5
* CSS3
* JavaScript

---

### 💬 2. Random Quotations

A simple application that displays random quotations using JavaScript.

**Features:**

* Generate random quotations
* Dynamic content updates
* Interactive button
* JavaScript DOM manipulation
* Simple and responsive interface

**Technologies:**

* HTML5
* CSS3
* JavaScript

## 🛠️ Technologies Used

* **HTML5** – Structure of the applications
* **CSS3** – Styling and layout
* **JavaScript** – Functionality and interactivity
* **DOM Manipulation** – Updating webpage content dynamically
* **JavaScript Events** – Handling user interactions

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/SufyanCh632/Javascript-Applications.git
```

2. Open the repository folder.

3. Open the desired application folder.

4. Open its `index.html` file in a web browser.

No server or additional installation is required.
